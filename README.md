## Другие проекты

### [Анализ бизнес-показателей. A/B-тесты](https://github.com/Roman-K11/Portfolio/tree/main/AB-test)
**Задача**: Проверка изменения поведения пользователей после изменении шрифтов в приложении по продаже продуктов питания с использованием A/B теста.
**Решение**:  
- Выявлено узкое место воронки продаж;
- По результатам A/A/B-теста с поправкой Бонферрони статистически значимых различий между контрольными группами (старые шрифты) и экспериментальной группой (новые шрифты) не обнаружено. Следовательно, изменение шрифтов не влияет на продажи негативно — новые шрифты могут быть внедрены в приложение.
  
**Стек**: `Python`, `Pandas`, `NumPy`, `SciPy`,  `Math`, `Matplotlib`, `Plotly`
